> 2026-08-04 작성. 노란 줄노트 + 손그림 낙서 + 실사 호랑이 콜라주 시안 기준.

## 1. 이미지로 줄 것 vs 코드로 그릴 것

손맛이 필요한 것만 이미지로 만들고, 나머지는 코드로 그린다. 코드로 그리면 기기별 크기 대응이
자동이고 파일 용량도 들지 않는다.

**이미지로 제작**
- 호랑이(중앙 히어로), 손그림 말풍선
- 낙서 5종: 고양이 / 상장·리본 / 음표 / 꽃 / 물결 / 불꽃
- 메뉴 아이콘 4종: 트로피 / 빨간 동그라미 / 구겨진 종이 / 트럼펫
- 발자국 **1개** (게이지용)

**코드로 처리 (에셋 불필요)**
- 노란 줄노트 배경 → 배경색 + 가로선 반복 View. 이미지로 하면 기기 높이별로 줄 간격이 안 맞는다
- "나의 자랑스런 업적" 초록 형광펜 → 배경색
- 발자국 채움/빈칸/현재 → 발자국 1장을 `tintColor`로 색만 바꾸고, 현재 슬롯 테두리는 View border
- 모든 텍스트 (아래 원칙 참고)

### ★ 이미지에 글씨를 넣지 않는다

"복습!", "테스트", "발음체크", "3일 연속", "DAY 148" 등은 전부 폰트로 렌더한다.
이미지에 박히면 ① 확대 시 깨지고 ② 숫자를 바꿀 수 없고 ③ 파일이 커진다.
**그림 부분만** 잘라서 준다.

## 2. 파일 규격

| 항목 | 규칙 |
|---|---|
| 형식 | 투명 배경 필요 → **PNG** / 사각 사진 → JPG |
| 해상도 | **@3x 기준 1장만** (@2x·@1x 불필요). 코드에서 크기를 지정한다 |
| 여백 | 그림 주변 투명 여백은 잘라낼 것 — 배치 계산이 틀어진다 |
| 용량 | TinyPNG 등으로 압축. `content.db`가 2.9MB라 이미지 총합 2MB 이내 권장 |
| 이름 | **영문 소문자 + 하이픈**만. 한글·공백·대문자 금지 |

권장 크기는 화면 폭 393pt(iPhone 기준) × 3배로 계산했다.

## 4. 폰트 — 나눔손글씨 중학생

`expo-font`가 Expo Go 번들에 포함돼 있어(~14.0.12) 추가 빌드 없이 쓸 수 있다.

- 위치: `assets/fonts/NanumMiddleSchool-Regular.ttf`
- **파일명을 반드시 영문으로** — 한글 파일명은 Android 빌드에서 경로 문제를 일으킨다
- 굵기가 하나뿐이면 `-Regular` 한 벌로 충분
- 적용은 `app/_layout.tsx`의 기존 초기화 게이트(`initDatabases` 대기 로직)에 폰트 로딩을 얹으면
  깜빡임 없이 처리된다

## 5. 폴더 정리 (에셋 작업 시 함께)

1. **`assets/images/호랑잉글리시.psd` (9.7MB)를 `design/`으로 이동.**
   `.psd`는 Metro의 기본 에셋 확장자라 앱 번들에 딸려 들어갈 수 있다. 원본 작업 파일은
   `assets/`에 두지 않는다. (이미 git에 커밋돼 있어 저장소 용량에도 영향)
2. **`assets/images/호랑잉글리시.png` → 영문 파일명으로 변경.** 같은 이유.

## 6. IP 확인 — [공개출시전-IP체크리스트.md](공개출시전-IP체크리스트.md) 연동

이번 시안에 그 문서에서 **교체 필수**로 분류해 둔 항목이 그대로 들어 있다.

- **발음체크의 혀** — 롤링스톤즈 로고. 트럼펫과 조합해도 혀 모양이 남아 있으면 동일한 문제
- **실사 호랑이 사진** — 라이선스 확인된 소스(CC0/Unsplash 등)인지 확인하고 **출처를 체크리스트에
  기록**해 둘 것. 나중에 증빙이 쉬워진다

가족용 TestFlight까지는 그대로 진행해도 된다고 이미 정리해 뒀으므로, 공개 출시를 결정하는
시점에 교체한다.

**추가할 항목**: 나눔손글씨 중학생은 상업적 이용이 가능한 무료 폰트지만, 앱 임베딩 조건과
저작권 표기 의무를 확인해 체크리스트에 한 줄 남길 것.

## 7. 구현 시 유의 (에셋 받은 뒤)

- 배치 비율은 시안대로 가되, 세로 여백은 유동으로 처리한다 — iPhone SE(작은 화면)에서 호랑이와
  하단 메뉴가 겹치지 않아야 한다
- 줄노트 가로선은 화면 높이에 맞춰 개수를 계산해 그린다
- 홈 화면의 기존 기능(오늘 단어장 진입, 4슬롯 게이지, 스트릭, 각 메뉴 라우팅)은 그대로 유지하고
  껍데기만 교체한다 — 라우팅·쿼리 로직은 건드리지 않는다
