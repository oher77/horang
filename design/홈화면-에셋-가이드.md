## 0. 확정 사항 요약 (2026-08-05)

| 항목 | 결정 |
|---|---|
| 작업 캔버스 | **기존 640 × 1155 그대로 유지** |
| 호랑이 | **원본 사진에서 크게 다시 잘라내기** (840px 이상) — 유일한 재작업 |
| 글자 | 전부 폰트로 렌더 → **포토샵에서 오리지 않음** |
| 상장·리본 낙서 | **삭제** |
| 꽃방귀 낙서 | **획득물 메뉴 버튼**으로 승격 (신규 페이지, 나중에 제작) |
| 고양이 낙서 | **설정 메뉴 버튼** |
| 테스트·발음체크 옆 표시 | 아이콘과 묶지 말고 **별도 deco로 분리** |

### 캔버스를 640으로 유지하는 이유

이론상 최신 아이폰은 @3x(iPhone 12 Pro = 1170px, 16 Pro = 1206px)라 640은 부족하다. 그러나
**실기기(12 Pro)에서 640 원본과 1179로 확대한 버전을 비교했을 때 차이가 보이지 않았다.**

- 확대본은 "1179처럼 보이는 640"일 뿐 — 없던 디테일이 생기지 않으므로 당연한 결과
- 이 시안은 **두꺼운 검은 선 + 큰 글씨 + 사진** 위주라 확대에 관대한 편
- 판단 기준은 스펙이 아니라 실제 기기 → 640으로 확정

단, **사진은 확대 손실이 가장 크게 드러나므로 호랑이만 원본에서 다시 뽑는다.** 호랑이만 해상도가
높고 나머지가 640 기준이어도 문제없다 — 코드에서 이미지별로 표시 크기를 따로 지정한다.

## 1. 이미지로 줄 것 vs 코드로 그릴 것

손맛이 필요한 것만 이미지로 만들고, 나머지는 코드로 그린다. 코드로 그리면 기기별 크기 대응이
자동이고 파일 용량도 들지 않는다.

**이미지로 제작**
- 호랑이(중앙 히어로), 손그림 말풍선
- 버튼 6종 (아래 3장 표 참고)
- 장식: 음표 / 불꽃 / 데코 2종
- 발자국 **1개** (게이지용)

**코드로 처리 (에셋 불필요)**
- 노란 줄노트 배경 → 배경색 + 가로선 반복 View. 이미지로 하면 기기 높이별로 줄 간격이 안 맞는다
- "나의 자랑스런 업적" 초록 형광펜 → 배경색
- 발자국 채움/빈칸/현재 → 발자국 1장을 `tintColor`로 색만 바꾸고, 현재 슬롯 테두리는 View border
- 파란 상자(습관 게이지 배경) → View
- 모든 텍스트 (아래 원칙 참고)

### ★ 이미지에 글씨를 넣지 않는다

"복습!", "테스트", "발음체크", "3일 연속", "DAY 148" 등은 전부 폰트로 렌더한다.
이미지에 박히면 ① 확대 시 깨지고 ② 숫자를 바꿀 수 없고 ③ 파일이 커진다.
**그림 부분만** 잘라서 준다.

## 2. 파일 규격

| 항목 | 규칙 |
|---|---|
| 형식 | 투명 배경 필요 → **PNG** / 사각 사진 → JPG |
| 크기 | 640 캔버스에서 **그려진 그대로** 오린다 (호랑이만 예외, 840px 이상) |
| 여백 | 그림 주변 투명 여백은 잘라낼 것 — 배치 계산이 틀어진다 |
| 용량 | TinyPNG 등으로 압축. `content.db`가 2.9MB라 이미지 총합 2MB 이내 권장 |
| 이름 | **영문 소문자 + 하이픈**만. 한글·공백·대문자 금지 |

### 포토샵 내보내기

레이어/그룹에서 **우클릭 → 빠른 내보내기 형식(PNG)** 을 쓰면 **그 레이어의 내용 크기로 자동으로
잘려서** 나온다. "투명 여백 제거"가 저절로 해결된다.

- 형식 PNG, 투명도 켜기, 배율 1x
- 여러 개를 한 번에 뽑으려면 `파일 > 내보내기 > 내보내기 형식`

### 데코 2종을 따로 오리는 이유

배치가 이렇기 때문이다.

```
   [구겨진 종이]      ← 아이콘 (위)
    테스트 ~         ← 글자(폰트) + 물결(데코)
```

데코는 아이콘이 아니라 **글자 옆**에 붙는다. 아이콘 이미지에 합치면 그 사이 빈 공간까지 투명
픽셀로 끌고 와야 해서 크기 지정이 어려워지고, 글자 크기를 바꾸면 위치가 어긋난다.

**물결(`~`)은 폰트로 대체될 수도 있다.** 나눔손글씨 중학생으로 `테스트~`라고 입력하면 손글씨
물결이 나온다. 먼저 폰트로 찍어보고 시안과 느낌이 다르면 그때 이미지를 쓴다(그래서 오려는 두되
안 쓸 수 있다). **체크(`✔`)는 이미지로 간다** — 한글 손글씨 폰트에 체크 글리프가 없는 경우가
많아 시스템 폰트로 대체되면 혼자 딱딱하게 튄다.

## 4. 폰트 — 나눔손글씨 중학생

`expo-font`가 Expo Go 번들에 포함돼 있어(~14.0.12) 추가 빌드 없이 쓸 수 있다.

- 위치: `assets/fonts/NanumMiddleSchool-Regular.ttf`
- **파일명을 반드시 영문으로** — 한글 파일명은 Android 빌드에서 경로 문제를 일으킨다
- 굵기가 하나뿐이면 `-Regular` 한 벌로 충분
- 적용은 `app/_layout.tsx`의 기존 초기화 게이트(`initDatabases` 대기 로직)에 폰트 로딩을 얹으면
  깜빡임 없이 처리된다

## 7. 구현 시 유의 (에셋 받은 뒤)

- **안전 영역**: 시안의 고양이 낙서가 맨 위에 붙어 있는데 실제 기기에서는 시계·다이나믹 아일랜드와
  겹친다. 구현 시 상단 여백을 확보해 아래로 내린다(코드에서 기기별 safe area로 처리).
- 배치 비율은 시안대로 가되 **세로 여백은 유동으로** — 시안 비율(1:1.80)이 구형 SE 기준이라
  최신 아이폰(1:2.17)에서는 세로가 20%쯤 남는다. 그 여유를 상단 안전영역과 요소 간격에 배분한다.
- 줄노트 가로선은 화면 높이에 맞춰 개수를 계산해 그린다
- 이미지는 `width` + `aspectRatio`로 크기를 줘 **어떤 기기에서도 비율이 찌그러지지 않게** 한다
- 홈 화면의 기존 기능(오늘 단어장 진입, 4슬롯 게이지, 스트릭, 각 메뉴 라우팅)은 그대로 유지하고
  껍데기만 교체한다 — 라우팅·쿼리 로직은 건드리지 않는다

### 미확정 — 구현 전 결정 필요

- **오늘의 단어장 진입점**: 시안에 "오늘의 단어장 시작하기"에 해당하는 버튼이 없다.
  호랑이+말풍선 전체를 탭 영역으로 잡는 안을 제안 상태(말풍선에 이미 DAY·단어 수가 있음).
- **획득물 페이지**: 기획만 있고 화면은 미정. 일단 `btn-collection`에서 라우팅만 연결해 두고
  페이지는 나중에 만든다.
