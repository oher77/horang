앱 소개

교육부 지정 필수 어휘를 하루 단위 단어장(Day 1, Day 2 …)으로 나눠 암기 → 복습 → 테스트로 이어지는 학습 흐름을 만듭니다. 단어는 Day 사이에 중복되지 않으며, 학습한 날로부터 1·3·7·14·30·60·120일 뒤에 자동으로 복습 대상이 됩니다.

  • 단어장 — 뜻 가리고 떠올리기, 스와이프로 기억 정도 표시, 단어를 누르면 발음 재생
  • 복습 — 간격 반복 일정에 따라 오늘 볼 지난 단어장을 자동으로 모아 줍니다
  • 테스트 — 하루 한 번, 단어→뜻 / 뜻→단어 / 쓰기 문제를 섞어 출제하고 직접 채점합니다
  • 용돈 장부 — 테스트 점수에 따른 금액을 기록하고 부모님이 지급 여부만 체크하는 장부입니다(앱 안에서 결제가 이뤄지지 않습니다)
  • 업적·자랑하기 — 성장 기록을 한 장의 리포트로 만들어 가족에게 공유할 수 있습니다

자주 묻는 질문

인터넷이 없어도 쓸 수 있나요?

네. 단어·뜻·예문이 모두 앱에 들어 있어 비행기 모드에서도 그대로 동작합니다.

학습 기록은 어디에 저장되나요?

기기 안에만 저장됩니다. 서버로 보내지 않으며 회원가입도 없습니다. 자세한 내용은 개인정보처리방침을 참고해 주세요.

기기를 바꾸면 기록이 옮겨지나요?

iCloud 기기 백업을 켜 두셨다면, 새 기기에서 백업을 복원할 때 학습 기록도 함께 복원됩니다. 다만 앱을 삭제했다가 다시 설치하면 기록은 복구되지 않습니다.

용돈이 실제로 결제되나요?

아니요. 점수에 따른 금액을 보여주고 부모님이 "줬음"을 체크하는 장부일 뿐이며, 앱 안에 결제 기능은 없습니다. 인앱 구매나 광고도 없습니다.

테스트를 하루에 여러 번 볼 수 있나요?

테스트 응시는 하루 한 번입니다. 다만 채점을 잘못했을 때 다시 채점하는 것은 가능합니다.

단어를 직접 추가할 수 있나요?

현재 버전에서는 지원하지 않습니다. 교육부 지정 어휘를 정해진 기간에 완주하는 것에 집중한 앱이기 때문입니다.
